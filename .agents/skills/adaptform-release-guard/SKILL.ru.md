# Контроль выпуска

[English](SKILL.md) · [Русский](SKILL.ru.md)

Применять, когда задача затрагивает документацию выпуска, метаданные пакета, состав дистрибутива или процессы публикации.

- Прочитать `package.json` и только соответствующий changelog или документ выпуска. Версия 2.1.0 опубликована 2026-10-14; будущие улучшения являются предложениями, а не обязательством нового выпуска.
- Различать проверку и публикацию: сборки и проверки содержимого пакета не разрешают публикацию, изменение версии, теги или релизы.
- Для согласованного изменения упаковки проверить ESM, CommonJS, декларации, необязательную точку входа Luxon и список файлов пакета; использовать существующие проверки без публикации.
- Обращаться к `docs/NPM_PUBLISH.ru.md` только для задачи публикации, а к `docs/roadmap/v2.1.0/` — когда это требуется правилами AGENTS.
- Записывать фактические проверки и ограничения; не отмечать исторические направления завершёнными и не выбирать будущую версию только из-за наличия предложения.
