# Публичные контракты

[English](SKILL.md) · [Русский](SKILL.ru.md)

Применять, когда согласованная задача меняет публичные экспорты, типы полей или форм, сериализацию, ошибки либо необязательную интеграцию Luxon.

- Начать с `src/index.ts` и `src/luxon.ts`; проследить только затронутые экспорты в `src/core/`.
- До изменений определить существующий контракт и его потребителей. Изучить соответствующий раздел README и точечные тесты, а не всю библиотеку.
- Сохранять вывод типов значений, форматы сериализации, публичные имена и сообщения валидации. Сохранять необязательность Luxon и независимость основной точки входа.
- Для согласованного изменения контракта описать влияние на совместимость и миграцию в соответствующей документации; выбирать проверки через `adaptform-targeted-tests`.
