# Жизненный цикл валидации

[English](SKILL.md) · [Русский](SKILL.ru.md)

Применять, когда согласованная задача затрагивает присваивание, приведение типов, порядок валидации, сброс, состояния touched или validity либо обновление коллекций.

- Найти владельца поведения в `src/core/fields/Field.ts`, `src/core/Form.ts` или нужном классе коллекции; прочитать только этот сценарий и точечные тесты.
- Проследить исходный ввод, приведение типов, присваивание, валидацию, ошибки и состояние. Различать чтение валидности и запуск проверки.
- Сохранять массовое присваивание до межполевой валидации, параметры отложенной проверки и семантику сброса из README.
- При необходимости проверять число вызовов валидатора и зависимые поля; для коллекций учитывать затронутое добавление, удаление и сброс.
- Добавлять точечный регрессионный тест только для согласованного изменения поведения или исправления; не перепроектировать жизненный цикл попутно.
