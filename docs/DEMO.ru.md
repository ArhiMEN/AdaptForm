# Интерактивное демо и GitHub Pages

[English](DEMO.md) · [Русский](DEMO.ru.md)

Адрес демо: **[https://arhimen.github.io/AdaptForm/](https://arhimen.github.io/AdaptForm/)**. GitHub Pages использует GitHub Actions, а среда `github-pages` разрешает публикацию из `v2.1.0` и `master`.

Страница собирается из приложения `demo/` и исходного кода библиотеки в `src/` выбранной ветки. Первая публикация использует `v2.1.0` и демонстрирует кандидата версии 2.1.0. После слияния этой ветки в `master` изменения `master` тоже публикуются автоматически. Обе ветки используют один адрес; последняя успешная публикация становится текущим демо.

## Что можно проверить

- Валидацию полей, состояния полей и корректность формы в реальном времени.
- Обязательные поля, шаблоны и длину строк, числовые диапазоны, ограничения дат, логические условия и условную обязательность.
- Добавление/удаление элементов `ArrayField` и ограничения коллекции.
- Редактирование и проверку вложенных форм `ArrayFormField`.
- Имитацию серверных ошибок через `Form.errors` и стандартное сопоставление `ErrorsSchema`.
- Преобразование ввода через `MaskPlugin`.
- `toJSON()` и читаемое представление `toFormData()`.
- Сброс и различия между состояниями «не изменено», «ожидает проверки», «корректно» и «ошибка».

Все значения остаются на текущей странице браузера. Демо не отправляет их на сервер.

## Языки

Выберите английский или русский в переключателе **Язык**. Выбор сохраняется в хранилище браузера, если оно доступно. Параметр URL `?lang=en` или `?lang=ru` имеет приоритет над сохранённым выбором; иначе используется сохранённый язык либо язык браузера, с английским по умолчанию.

Переключение сохраняет значения, состояния валидации, элементы коллекций и выбранную вкладку сериализации. Сообщения валидации и имитируемого сервера в демо переводятся при отображении; встроенные сообщения библиотеки и публичный API не изменены. Ссылки на документацию и историю изменений открывают выбранный язык.

Прямые ссылки: [Английское демо](https://arhimen.github.io/AdaptForm/?lang=en) · [Русское демо](https://arhimen.github.io/AdaptForm/?lang=ru).

## Локальный запуск

Используйте Node.js 22 и npm, как в CI:

```bash
npm ci
npm run check:demo
npm run build:demo
npm run dev -- --config demo/vite.config.ts
```

Сервер разработки Vite использует корневой путь, производственная сборка — базовый путь GitHub Pages `/AdaptForm/`. Сборка записывается в `dist-demo/`, который исключён из npm-пакета.

## Автоматическая публикация

Workflow `.github/workflows/deploy-demo.yml` собирает и публикует сайт при изменении `demo/`, `src/`, метаданных пакета или самого workflow в `v2.1.0` либо `master`. Его можно запустить вручную через **Deploy demo** в GitHub Actions, выбрав ветку, содержащую workflow.

Workflow проверяет типы демо, создаёт производственную сборку и загружает статический сайт в GitHub Pages. Основной CI независимо проверяет типы и сборку демо.

### Если Pages ещё не включён

В настройках репозитория откройте **Settings → Pages** и выберите источник **GitHub Actions**. Эта однократная настройка требует прав владельца/администратора и не изменяется коммитом. Затем повторно запустите **Deploy demo** из `v2.1.0`. Workflow соберёт сайт и опубликует по адресу выше.

В **Settings → Environments → github-pages → Deployment branches and tags** разрешите `v2.1.0` и `master`. Одного включения Pages недостаточно: среда может разрешать только `master` и блокировать `v2.1.0` даже при успешной сборке. В этом проекте обе настройки уже выполнены.

## Обновление демо

- Поддерживайте английскую и русскую версии интерфейса и документации. Комментарии и примеры кода оставляйте на английском.
- Импортируйте публичный API из `../src/index.ts`, не дублируя логику библиотеки в демо.
- Согласуйте базовый путь Vite с названием репозитория.
- Добавляйте взаимодействия в `demo/main.ts`, а оформление — в `demo/style.css`.
- Перед коммитом запускайте `npm run lint`, `npm run check:demo` и `npm run build:demo`.
