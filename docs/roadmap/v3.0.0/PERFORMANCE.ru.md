# Проверка производительности AdaptForm 3.0

[English](PERFORMANCE.md) · [Русский](PERFORMANCE.ru.md)

## Парные замеры ядра

База `f13e862970869a0bab73ddab5730713979dde15b` содержит завершённый клиентский этап. Собранные пакеты проверялись в одном процессе Node 24.19.0 на AMD EPYC 9V45. Парный сценарий включал 1000 полей или элементов, 20 прогревочных операций и девять выборок по 20 операций. Порядок базы и кандидата чередовался.

| Операция | Медиана базы | Медиана кандидата |
| --- | ---: | ---: |
| Чтение неизменившегося снапшота | 0,826 мс | 0,930 мс |
| Запись поля с подпиской | 1,745 мс | 1,648 мс |
| Batch из 10 записей | 4,802 мс | 4,274 мс |
| Вставка и удаление скалярного элемента | 1,078 мс | 1,041 мс |
| Вставка и удаление вложенной Form | 7,837 мс | 9,367 мс |

Безопасный поиск полей и отслеживание позиций операций добавляют работу в некоторых сценариях. Остаточный рост медианы в этом прогоне составил около 13% для чтения большого неизменившегося снапшота и 20% для вставки и удаления вложенной формы. При обновлении коллекции используются связи сохранённых элементов. Поиск полей переиспользуется в одной волне снапшотов. Замеры сделаны на одном хосте и не задают пороги CI.

## Замеры серверного контура

Начало операции, разбор и применение измерены отдельно. Для каждого сценария выполнено пять прогревов и семь измерений. Скрипт проверяет число записей, одно уведомление на замену и завершённую доставку. Плоские сценарии содержат 1000 полей, вложенный включает пять уровней коллекций.

| Сценарий | Медиана начала | Медиана разбора | Медиана Apply |
| --- | ---: | ---: | ---: |
| 500 ошибок одного поля | 1,62 мс | 2,96 мс | 6,16 мс |
| 5000 ошибок одного поля | 1,33 мс | 23,17 мс | 13,10 мс |
| 1000 ошибок на 1000 полях | 0,93 мс | 3,60 мс | 7,51 мс |
| 1000 ошибок через 1000 статических маппингов | 1,07 мс | 8,03 мс | 12,29 мс |
| 100 ошибок на глубине пяти коллекций | 0,03 мс | 0,52 мс | 0,55 мс |

В сценарии со 100 областями heap составил около 10,12 МиБ до создания 1000 токенов, 10,52 МиБ при удержании всех токенов и 9,90 МиБ после сброса ссылок и принудительного GC. Измерения всего процесса включают шум аллокаций и сборки мусора. Реестр использует слабые ключи и хранит последнюю операцию по каждому узлу области.

```bash
npm run build
node scripts/benchmark-error-model.mjs /path/to/baseline/dist/index.mjs paired.json
node --expose-gc scripts/benchmark-v3-server.mjs server.json
```
