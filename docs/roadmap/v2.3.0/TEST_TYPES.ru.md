# STAB-01 — типизация тестов

[English](TEST_TYPES.md) · [Русский](TEST_TYPES.ru.md)

База: master `9942aac71dbd5b20121f634bbad5663a812ef6ee`, пакет 2.2.0. Node 24.19.0, npm 11.9.0, TypeScript из `npm ci` (lockfile не изменён). Это исходный код следующего milestone, не npm-релиз.

`npx tsc --noEmit -p tsconfig.test.json`: воспроизведены **54 диагностики**, осталось **0**:

Цикл TS2589: `keyof this` → проверка `fieldsValue` → `FormFieldsValue<this>`. Базовые члены Form не могут быть сериализуемыми полями. Предварительная фильтрация сохраняет вывод типов значений и устраняет цикл без ограничения глубины и расширения типов. Regression tests проверяют скаляры, коллекции, несколько уровней вложенности, конечный доступ в рекурсивных моделях, исключение metadata и отклонение неверных контекстов, значений и async-контрактов. `@ts-expect-error` используется только в намеренных отрицательных regression cases, не для подавления существующих ошибок.

Тесты не исключены, strict не ослаблен, массового `any`, ослабления API и изменений runtime нет. Существующая необходимость аннотировать параметр значения generic-фабрики ArrayField сохраняется; переработка вывода типов сюда не входит. Блокеров с breaking change для этих 54 диагностик не осталось.

Проверки: типизация исходников и тестов, lint и точечные тесты STAB-01. Финальные проверки проекта приведены в [VERIFICATION](VERIFICATION.ru.md). CI теперь также проверяет тестовый tsconfig для предотвращения регрессий.
