# AdaptForm 2.1.1 — подготовка релиза

[English](RELEASE.md) · [Русский](RELEASE.ru.md)

## Статус

**Кандидат подготовлен; версия НЕ опубликована в npm.** Документ отслеживает метаданные 2.1.1 и готовность релиза, но не является GitHub Release или тегом. На момент начала подготовки 2026-10-17 актуальная npm-версия была `2.1.0`, а `2.1.1` в реестре отсутствовала. Перед публикацией проверить повторно.

Новые публичные типы, формат сериализации, обязательные runtime-зависимости, адаптеры фреймворков и функции демо не добавляются. `toJSON()` по-прежнему сериализует непроверенные данные; перед отправкой нужна явная проверка. Значения с завершающей десятичной точкой теперь намеренно невалидны. `ArrayField.itemsValue` сохранён.

## Подготовка пакета

- Версия в `package.json` и корневой записи `package-lock.json` — **2.1.1**.
- Changelog, README и сопровождающие документы согласованы на EN/RU; до публикации указывать статус **Не опубликована**.
- Существующие точки входа `.` и `./luxon` сохраняют ESM, CommonJS и декларации TypeScript.
- Состав публикуемых файлов, необязательная peer-зависимость `luxon` и workflow публикации не меняются.

## Безопасная передача на публикацию

При подготовке не выполнять `npm publish`, не создавать GitHub Release или теги, не менять npm-ключи и не включать автоматическую публикацию. Перед реальным выпуском следовать [NPM_PUBLISH.ru.md](../../NPM_PUBLISH.ru.md) и проверить опубликованный архив. Существующие Git-ветки сохранять.
