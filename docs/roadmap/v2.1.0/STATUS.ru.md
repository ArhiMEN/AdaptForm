## Известные ограничения

### Автоматическая публикация в npm — 2026-10-14

Сопровождающий запросил автоматическую публикацию в npm после слияний в `master` с версией из `package.json`. Подготовлены workflow с защитным переключателем и проверка версии, добавлены семь регрессионных тестов. Включение ожидает действий владельца: npm отклонил настройку Trusted Publisher с HTTP 403 и требованием включить 2FA учётной записи. Секрет npm на GitHub не настроен. До регистрации Trusted Publisher либо настройки granular-токена `NPM_TOKEN` и установки `NPM_PUBLISH_ENABLED=true` workflow пропускает публикацию. Теги и релизы GitHub эта настройка не создаёт. См. [инструкцию](../../NPM_PUBLISH.ru.md).

Изменения доставлены через [PR #2](https://github.com/ArhiMEN/AdaptForm/pull/2), коммит слияния `391db730`. CI ветки и [CI master 38546431178](https://github.com/ArhiMEN/AdaptForm/actions/runs/38546431178) прошли. [Запуск публикации 38546494455](https://github.com/ArhiMEN/AdaptForm/actions/runs/38546494455) был пропущен как задумано: `NPM_PUBLISH_ENABLED=false`. Локально прошли 374 теста, lint, аудит, сборка и проверка типов библиотеки и демо, проверка состава пакета. Покрытие новой проверки выпуска: 95% операторов, 96,4% ветвей и 100% функций. Текущая версия npm остаётся 2.0.5.


- Обе разрешённые ветки используют один адрес демо; последняя успешная публикация заменяет сайт. Автоматическая публикация из `master` проверена.

- Старые callback API содержат `any` там, где замена на `unknown` нарушит совместимость исходного кода. Вывод значений, результаты сериализации и вложенные коллекции уточнены без массовой переработки callback API.
- Runtime или интеграционные тесты PlayLease не запускались согласно явно выбранной области работы.
- Последняя опубликованная версия npm — `2.0.5`; ветка подготовлена как `2.1.0`, но выпуск не опубликован.
