# План улучшений AdaptForm 2.1.0

[English](PLAN.md) · [Русский](PLAN.ru.md)

## Цель

Повысить надёжность, типобезопасность, удобство сопровождения и готовность AdaptForm к выпуску, сохраняя существующее поведение для потребителей везде, где возможно. Ветка охватывает библиотеку; интеграционные проверки конкретных приложений ведутся отдельно.

Интерактивное демо: [https://arhimen.github.io/AdaptForm/](https://arhimen.github.io/AdaptForm/) (GitHub Pages и разрешения настроены для `v2.1.0` и `master`; см. [docs/DEMO.ru.md](../../DEMO.ru.md)).

- [x] Добавить проверки типов при компиляции для форм, массивов и вложенных форм.

## Критерии готовности

- Существующие тесты проходят; прежние ошибки, если есть, явно описаны и отделены от регрессий.
- Новое поведение покрыто регрессионными тестами, включая граничные случаи.
- Сборка и генерация деклараций TypeScript проходят.
- Публичный API и сериализация описаны точно.
- Существующая логика улучшается без дублирования реализации.
- Документация и демо доступны на английском и русском. Комментарии, тестовые описания и примеры кода остаются на английском; локализация сообщений библиотеки явно отложена.
- Интеграция конкретных приложений и локализация сообщений библиотеки вынесены в отдельную задачу.
- Не выполняются удаление репозитория или веток, переписывание истории, GitHub release или публикация в npm.
