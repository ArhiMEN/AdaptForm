# Решения

## Принятый процесс — 2026-10-17

- Владелец обсуждает архитектуру и улучшения в ChatGPT. Реализация выполняется через Codex Cloud только после отдельного явного согласования задачи и её границ. Обсуждение, запись в backlog или skill не разрешают реализацию.
- Эта задача разрешает только основу инфраструктуры AI-агентов: skills, документы контекста проекта и минимальные дополнения AGENTS. Она не разрешает менять библиотеку, тесты, зависимости, версию пакета или адаптеры фреймворков.
- Сохранять публичные контракты и существующие правила безопасности репозитория. Загружать skills выборочно; использовать минимальные полезные проверки.
- Хранить только публичные результаты, относящиеся к проекту. Не переносить персональные данные, приватные переписки, секреты, токены или внутреннюю закрытую информацию в файлы, коммиты и PR.

## Исходное состояние выпуска

Версия 2.1.0 опубликована 2026-10-14. Будущие улучшения являются предложениями; следующая версия, дата выпуска, фреймворк или план реализации здесь не согласованы.

Последующие решения дополнять короткой датированной записью результата, обоснования, согласованных границ и публичной ссылки на согласование, если она есть. Не вставлять стенограммы обсуждений. Синхронизировать английскую версию.

## Выбранное направление — 2026-10-17

- **Согласовано продуктовое направление:** AdaptForm развивается в независимый от UI-фреймворков, основанный на классах **headless form engine** (вариант B). Адаптеры могут разрабатываться отдельно и необязательно.
- **Это решение не согласовывает автоматически:** изменения кода, конкретные публичные API, версии, даты релизов, миграции семантики или зависимости от фреймворков. 20 [задач плана](HEADLESS_ROADMAP.ru.md) остаются предложениями с отдельными контрольными точками.
- Архитектуру обсуждают в ChatGPT; реализация только отдельными согласованными заданиями Codex Cloud. Не переносить частные стенограммы в публичный Git.

## HF-003: политика десятичного ввода — 2026-10-17

- Согласованные границы: исправить валидацию незавершённых десятичных чисел, сохранив существующий жизненный цикл Field/Form и контракты сериализации.
- Строки с завершающим разделителем, например `123.`, `0.`, `-123.` и нормализованное `123,`, остаются доступны для редактирования: исходный ввод сохраняется, а приведение по-прежнему возвращает нормализованную строку. Каждая явная проверка отклоняет их с ошибкой формата независимо от числовых границ, используя `messages.invalid` или существующее сообщение по умолчанию для пустой дробной части.
- Завершённые значения сохраняют ограничения `gt`/`ge`/`lt`/`le`, точности и количества цифр, поддержку отрицательных чисел и числового ввода. Избыточная точность отклоняется без округления.
- Отложенное присваивание сохраняется через `setRawValue(value, false)` и `setFields(data, false)`. Приложения обязаны вызывать `checkAndSetValid()` или `Form.checkValid()` перед использованием итоговой валидности; `toJSON()` сериализует без проверки.
- Влияние на совместимость: ранее принимавшиеся валидацией незавершённые числа теперь намеренно отклоняются. Публичные типы и представления сериализованных данных сохранены. Триггеры отображения ошибок, новые состояния разбора, reset коллекций и семантика touched остаются отдельными задачами. Завершение HF-003 требует успешных проверок, независимого ревью и принятия PR.

## Комплексная реализация HF-005–HF-010 — 2026-10-18

Разрешено последовательно реализовать фундамент headless-состояний в одной feature-ветке с коммитами для ревью и одним интеграционным PR. Сохранены touched, состав/цель reset, валидация вне явного batch, сериализация и необязательный Luxon 2.1.1. Добавлены baseline очищенных значений/dirty, неизменяемые snapshots данных, общие подписки, синхронный batch с отложенной итоговой автоматической проверкой без отката при исключениях и очистка вложенного владения. [Контракт](HEADLESS_STATE_CONTRACT.ru.md) и [примеры](HEADLESS_STATE_USAGE.ru.md) задают минимальный аддитивный API. Reinitialize — только предложение; HF-004/HF-011+ и релиз исключены. Без повышения версии, merge, тегов, npm-публикации и удаления веток.

## Foundation STAB-01/02 и HF-011 — 2026-10-20

Утверждённый объём задачи: одна ветка следующего milestone, четыре последовательных коммита и один интеграционный PR без merge и публикации; пакет остаётся 2.2.0. Для этого запуска прежняя политика остановки после каждой задачи заменена явным общим объёмом. STAB-01 фильтрует базовые члены Form до рекурсивной проверки mapped type с сохранением строгого вывода; все 54 исходные диагностики тестов исправлены без ослабления публичных контрактов. STAB-02 фиксирует измеренные ограничения без переработки scheduler.

HF-011 использует weak ID с объектными ключами и опциональный аддитивный itemIds snapshot для структурной совместимости. Insert принимает 0..length; move использует конечные индексы 0..length-1; некорректные/equal moves дают no-op. Существующие setters замены, payload, touched/reset/baseline сохранены. Dirty зависит от содержимого. Подробности: [контракт идентичности](HEADLESS_COLLECTION_IDENTITY.ru.md). HF-012 — только спецификация; предложенный dependency API не является принятым решением реализации. HF-004 и HF-013+ исключены.

## Ограниченная реализация HF-013 — 2026-10-21

Утверждённый объём: зависимости обычных Field одной Form, явная активация/отключение, выборочные синхронные проверки, цепочки/ромбы, ошибки циклов/отсутствующих источников и совместимость batch/snapshots/subscriptions. Это отменяет прежнее исключение HF-013 только для данной задачи. Реализация в `feature/v2.3.0-dependent-validation` от master `30a45a2`, PR в master без слияния и удаления веток. Версия пакета остаётся 2.2.0; публикации нет.

Минимальное безопасное подмножество: `dependsOn: [{path: ['fieldName']}]`, без прямых ссылок, scope, вложенных/позиционных путей и dependency options коллекций. Явный opt-in принимает декларирование контекста всего pipeline, чистоту callbacks, отклонение мутаций и configuration exceptions с сохранением записей и требованием успешной пересборки. Неактивированные формы сохраняют существующие контракты. Общие узлы/пересекающиеся деревья графов отклоняются; расширенное предложение HF-012 остаётся неутверждённым. [Реализованный контракт и ограничения](HEADLESS_DEPENDENCIES_USAGE.ru.md).
